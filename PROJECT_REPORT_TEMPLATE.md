# Student Management System – Project Report

## 1. Project Overview
A CRUD-based web application for managing student records.

## 2. Problem Statement
Manual student record management can be difficult to maintain. This application provides a simple digital system for creating, viewing, updating and deleting student records.

## 3. Objectives
- Implement CRUD operations.
- Build a responsive frontend.
- Create REST APIs.
- Store records in SQLite.
- Validate user input.
- Test API operations.

## 4. Technology Stack
HTML, CSS, JavaScript, Django REST Framework, SQLite, Postman, Git/GitHub.

## 5. Architecture
User → Frontend → REST API → Django Backend → SQLite Database

## 6. Database
Student fields: id, name, register_number, department, email, phone.

## 7. CRUD Implementation
- Create: POST
- Read: GET
- Update: PUT
- Delete: DELETE

## 8. Validation
Required fields, email validation, 10-digit phone validation and unique register number/email.

## 9. Testing
Record screenshots of successful GET, POST, PUT and DELETE requests in Postman.

## 10. Challenges and Solutions
Write the actual issues faced while installing dependencies, connecting frontend/backend and testing APIs.

## 11. Future Enhancements
Authentication, pagination, advanced filtering, deployment and role-based access.

## 12. Conclusion
The application demonstrates a complete CRUD workflow with frontend, REST API, backend and database integration.
